# 英语教学大纲

> 适用年级：幼小衔接～小学1-5年级（目标上海三公/小托福）
> 依据：全国2022版义务教育英语课程标准 + 上海牛津版课标 + 小托福标准
> 目标人群：上海地区儿童

---

## 一、总体目标

### 1.1 全国课标总体目标

| 年级 | 词汇要求 | 能力要求 |
|------|----------|----------|
| 3-4年级 | 200-300词 | 听说为主、简单认读 |
| 5-6年级 | 350-500词 | 简单读写、短篇阅读 |
| 课外阅读 | 累计4万词 | - |

### 1.2 上海课标特点（与全国差异）——关键差异

> ⚠️ **上海是全国少数从小学1年级就开设英语课的地区之一**，比全国早两年，这是最大差异。

| 对比项 | 全国标准（人教版） | 上海标准（牛津上海版） |
|--------|-------------------|----------------------|
| 起始年级 | **3年级** | **1年级** |
| 小学总词汇量 | 400-500词 | **约2000词（全国4倍）** |
| 课外阅读量 | 4万词 | **15万词（全国近4倍）** |
| 能力侧重 | 听说为主 | **听说读写并重** |
| 写作要求 | 5-6年级简单写 | **3年级开始写，5年级短篇作文** |
| 教材版本 | 人教版/部编版 | **牛津上海版（难度更高）** |
| 口语要求 | 简单对话 | **场景化口语运用** |

## 二、分年级知识点清单

### 2.1 幼小衔接阶段（幼儿园大班～一年级）

**核心目标**：英语启蒙，建立兴趣，听力词汇积累

> 📌 **上海特别说明**：上海1年级开始正式英语学习，需要提前启蒙准备

| 模块 | 内容 | 能力要求 |
|------|------|----------|
| 字母认知 | 26个字母大小写 | 会认、会读、会写 |
| 自然拼读 | Letter Sound（字母音） | 建立拼读意识 |
| 基础词汇 | 颜色、数字、动物、家庭成员等100词 | 听说认读 |
| 日常口语 | Hello/Bye/Thank you等20句型 | 听说表达 |
| 英语儿歌 | 10首经典英文儿歌 | 演唱、简单理解 |
| 英语绘本 | 简单分级绘本10本 | 理解故事 |

### 2.2 二年级

| 模块 | 内容 | 能力要求 | 词汇量 |
|------|------|----------|--------|
| 自然拼读 | 短元音、长元音拼读 | 见词能读 | +200词 |
| 核心句型 | This is... / I like... / He/She is... | 口头运用 | +150词 |
| 基础阅读 | RAZ A-B级绘本20本 | 理解阅读 | 累计450词 |
| 听力训练 | 简单课堂指令、对话 | 听懂做出反应 | - |
| 口语表达 | 自我介绍、爱好、天气等话题 | 能说3-5句 | - |

### 2.3 三年级（上海起始年级，正式系统学习）

| 模块 | 内容 | 能力要求 | 词汇量 |
|------|------|----------|--------|
| 字母与拼写 | 大小写、字母组合 | 准确书写 | +200词 |
| 核心语法 | be动词、现在进行时、一般现在时 | 理解运用 | - |
| 词汇 | 食物、衣服、学校、颜色等 | 听说读写 | 累计850词 |
| 阅读 | RAZ C-D级、简单桥梁书 | 独立阅读 | - |
| 写作 | 看图写句子、仿写 | 写3-5句 | - |
| 口语 | 问路、购物、打电话等场景 | 口语交流 | - |

### 2.4 四年级

| 模块 | 内容 | 能力要求 | 词汇量 |
|------|------|----------|--------|
| 语法系统 | 时态（过去时、将来时）、名词所有格 | 系统掌握 | +300词 |
| 阅读 | RAZ E-F级、短篇故事 | 理解主旨细节 | 累计1200词 |
| 写作 | 看图写话、邮件、日记 | 写一段话 | - |
| 小托福衔接 | 核心语法点、高频词汇 | 备考基础 | - |
| 听力理解 | 课堂说明、简单学术内容 | 抓取关键信息 | - |

### 2.5 五年级

| 模块 | 内容 | 能力要求 | 词汇量 |
|------|------|----------|
| 语法精通 | 从句、非谓语、虚拟语气 | 复杂句型运用 | +400词 |
| 阅读 | 初中难度文章、科普短文 | 深度理解 | 累计1600词+ |
| 写作 | 正式书信、短文、议论文开头 | 150字以上 | - |
| 小托福冲刺 | 听说读写全科训练 | 目标865+ | 核心词汇4500+ |

## 四、小托福(TOEFL Junior)备考体系

### 4.1 考试结构

| 部分 | 时间 | 题量 | 分值 | 核心考点 |
|------|------|------|------|----------|
| 听力 | 40分钟 | 42题 | 300分 | 课堂说明、校园对话、学术讲座 |
| 语言形式与含义 | 25分钟 | 42题 | 300分 | 语法、词汇、固定搭配 |
| 阅读 | 50分钟 | 42题 | 300分 | 非学术+学术短文理解 |
| 总分 | - | 126题 | 900分 | 目标865+（5级） |

### 4.2 核心语法清单

| 语法点 | 具体内容 | 难度 |
|--------|----------|------|
| 动词时态 | 一般现在时、现在进行时、一般过去时、一般将来时、现在完成时 | ★★★ |
| 被动语态 | 现在时/过去时被动语态 | ★★★★ |
| 非谓语 | to do / doing / done | ★★★★ |
| 主谓一致 | 单数/复数主语一致规则 | ★★ |
| 宾语从句 | that/if/whether引导 | ★★★ |
| 定语从句 | who/which/that引导 | ★★★★ |
| 状语从句 | 时间/原因/条件/结果状语从句 | ★★★ |
| 虚拟语气 | if从句（与现在/过去事实相反） | ★★★★★ |
| 固定搭配 | 介词搭配、动词短语、习惯用语 | ★★★ |
| 比较级/最高级 | 原级/比较级/最高级规则 | ★★ |

### 4.3 核心词汇要求（4500-6000词）

| 词汇级别 | CEFR对标 | 词汇量 | 适用场景 |
|----------|----------|--------|----------|
| 基础词汇 | A2 | 1200-1500词 | 日常对话、基本阅读 |
| 中级词汇 | B1 | 2500-3000词 | 学校场景、简单学术 |
| 高级词汇 | B2 | 4000-4500词 | 学术阅读、写作 |
| 小托福目标 | B1-B2 | 4500-6000词 | 考试达标 |

### 4.4 上海三公英语备考要求

> 📌 **上海三公学校（上外附中、浦外等）明确要求英语小托福865+，是重要选拔标准**

三公学校英语选拔重点：
- **口语表达**：简单英语问答、看图说话
- **词汇认读**：基础词汇掌握
- **绘本阅读**：简单英文绘本理解
- **综合能力**：表现力、沟通能力

## 六、AI生成内容设计要点

### 6.1 英文绘本设计

- **难度控制**：严格按孩子词汇量（上海1年级200词起步）
- **主题**：公主、小动物、校园生活、探险
- **画风**：统一卡通风格、柔和配色
- **配置**：AI标准童声朗读、逐句高亮、跟读评分
- **类型**：生活故事、科普故事、节日故事

### 6.2 单词闯关设计

- **游戏化**：单词消消乐、拼写大挑战、听音识词
- **记忆法**：自然拼读、词根词缀、图像联想
- **复习机制**：艾宾浩斯遗忘曲线自动安排复习
- **激励机制**：连续打卡奖励、勋章解锁

### 6.3 口语跟读设计

- **评分机制**：AI实时评分（发音准确度、流利度）
- **跟读材料**：绘本原文、日常对话、场景对话
- **纠错反馈**：指出错误点，给出正确示范
- **难度递进**：单词 → 短语 → 句子 → 段落
