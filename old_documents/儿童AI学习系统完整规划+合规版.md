## 一、项目核心定位

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 目标人群 | **上海** 6 岁幼小衔接 → 小学 1～5 年级儿童 |
| 开发模式 | 程序员个人独立全栈开发 + AI 全程辅助内容生成 |
| 使用场景 | 电脑后台运行 + 电视大屏投屏 + 电脑本机息屏 |
| 交互方式 | 搭配无线游戏手柄操控，学习游戏化 |
| 商业路径 | 自家孩子内测打磨 → 真实成长案例做口碑 → 宝妈圈层裂变 → 全包年费会员变现 |

### 1.2 产品定位声明

**核心属性**：AI 大屏护眼学习辅助工具，**不属于学科培训**

- 仅做练习、阅读、闯关、错题巩固、学情记录
- 无授课教学行为，不受周末/节假日时间限制

### 1.3 竞品格局

市面无同维度直接对手，区别于：
- 沪学习（仅课本同步）
- 斑马/小猴（单科录播）
- 步步高/讯飞学习机（硬件昂贵）
- 主打：**上海本地化** + 全科连贯进阶 + AI 千人千面定制 + 三公升学完整导向

## 二、产品整体设计总体思路

### 2.1 技术架构（前后端分离）

```
┌─────────────────────────────────────────────────────────┐
│                    前端 H5 网页                          │
│  (电视大屏适配、手柄按键监听、游戏化界面、卡通画风)         │
└─────────────────────────────────────────────────────────┘
                          │ HTTP API
                          ▼
┌─────────────────────────────────────────────────────────┐
│                 后端 Python FastAPI                      │
│  - AI 调度中枢（动态生成绘本/题库/阅读材料）               │
│  - 用户档案管理（识字量/词汇量/薄弱点/进度）              │
│  - 学习记录与错题本                                     │
│  - 会员权限控制                                         │
└─────────────────────────────────────────────────────────┘
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
    ┌──────────┐   ┌──────────┐   ┌──────────┐
    │  AI API  │   │ 数据库   │   │ 语音/图  │
    │ (生成内容)│   │ (SQLite)│   │  生成服务│
    └──────────┘   └──────────┘   └──────────┘
```

**核心技术选型**：
- 后端：Python FastAPI（轻量化、易部署、异步任务支持好）
- 数据库：SQLite（前期单人使用足够，后期可迁移 MySQL）
- 前端：原生 HTML5 + CSS3 + JavaScript（无需框架，学习成本低）
- AI 接口：调用第三方大模型 API（文本生成）+ 文生图 API（绘本配图）+ 语音合成
- 部署：腾讯云轻量应用服务器

### 2.2 内容底层大纲体系

系统内置**上海本地课标**作为核心大纲，适配上海教材进度、三公升学隐性要求：

| 大纲 | 来源 | 用途 |
|------|------|------|
| 上海课标 | 上海本地小学课程标准 | 适配上海教材进度、升学要求 |

### 2.3 拓展拔高体系（后期迭代接入）

| 体系 | 内容 | 对标目标 |
|------|------|----------|
| 上海三公思维训练 | 浅奥、数论、几何、逻辑推理、图形规律 | 上海三公（上实/上外/浦外） |
| 小托福 TOEFL Junior | 完整知识点、词汇、语法、阅读大纲 | 小托福 865+ |
| AMC8 | 代数、几何、数论、组合概率四大模块 | AMC8 20分+ |

### 2.4 核心学习模块规划

#### 2.4.1 语文模块

**孩子现有基础**：已掌握约 1000 个汉字（远超幼升小平均水平 300-500 字）

**学习定位**：不再做低阶重复识字，重点转向：

| 子模块 | 内容说明 |
|--------|----------|
| 分级阅读 | AI 生成匹配识字量的中文绘本，大字投屏朗读 |
| 阅读理解 | 智能阅读理解出题与答疑 |
| 拼音系统强化 | 声母/韵母/整体认读闯关、两拼/三拼练习（**上海一年级不考拼音，二年级才考**） |
| 生字笔顺/结构 | 笔画笔顺动画演示、组词、造句 |
| 看图说话 | 口头表达训练，引导完整句 |
| 国学古诗 | 短篇文言启蒙，带配图和朗读 |

#### 2.4.2 英语模块

**孩子现有基础**：约 800 核心词汇

**学习定位**：AI 定制分级英文绘本、听音识图、短句跟读、情景对话、逐步衔接小托福

> 📌 **上海特别说明**：上海小学英语从1年级开始（全国3年级才开课），词汇量要求约2000词（全国4倍）

**绘本实现最佳实践**：
1. 一次性 AI 生成统一画风专属人物/场景 IP（永久复用）
2. AI 按孩子词汇量编写适配故事文本
3. 固定插画模板 + AI 文字排版，生成大屏投屏电子绘本
4. 自带 AI 标准童声朗读、逐句高亮跟读

#### 2.4.3 数学模块

**学习定位**：幼小衔接口算、凑十/破十法动画拆解、10/20/50以内进退位、图形几何、应用题、浅奥思维启蒙

> 📌 **上海特别说明**：上海数学提前渗透代数思维（一年级即引入□+5=9类型），应用题更灵活

**AI 能力**：
- 按孩子水平动态生成口算题
- 专项练习题
- 错题自动生成同类巩固题
- 知识点查漏补缺

#### 2.4.4 思维拔高模块

**对标**：上海三公、AMC8 考点

**覆盖**：数论、平面几何、立体展开图、排列组合、逻辑推理、找规律、定义新运算

#### 2.4.5 学情档案智能模块

每个孩子独立专属档案，自动记录更新：

- 年龄、年级、识字量、英语词汇量
- 已掌握知识点、薄弱知识点
- 每日/每周学习时长、做题正确率
- 错题本自动归集
- AI 自动安排复习计划

### 2.5 护眼 & 专属交互设计

| 设计 | 实现方式 |
|------|----------|
| 电脑投屏 | 系统设置为「仅电视第二屏幕显示」，本机电脑息屏黑屏 |
| 外设操控 | 无线 2.4G 游戏手柄，按键映射：翻页、选题、确认、返回、重新闯关 |
| 大屏适配 | 电视比例适配，字体超大、元素大、配色柔和、无高闪烁特效 |

## 四、服务器选型 & 不同用户规模配置标准

### 4.1 服务商选择

**首选：腾讯云轻量应用服务器**

优势：性价比高、续费良心、上海节点延迟低、部署简单、新手运维省心

### 4.2 分用户规模配置

| 用户规模 | 配置 | 费用 |
|----------|------|------|
| 初期 5 个用户（自用+亲友内测） | 2核 2G / 4M带宽 / 50G SSD | 首年 99 元 |
| 中期 50 个付费用户（宝妈小圈子） | 2核 4G / 5M带宽 / 50G SSD | 年 400-600 元 |
| 后期 500 个稳定付费用户 | 4核 8G / 8-10M带宽 / 80G SSD | 年 800-1200 元 |

### 4.3 部署原则

- 前期全部调用第三方 AI 接口，不本地部署大模型
- 大幅降低服务器配置和运维压力
- 用户体量做大后再考虑架构扩容

## 九、项目合规完整体系

### 9.1 产品定性

**不属于学科培训，属于学习辅助工具**

| 学科培训特征 | 本项目特征 |
|-------------|-----------|
| 以提分、补课、系统授课为目的 | 仅做绘本阅读、题库闯关、口算练习 |
| 有老师教学行为 | 无真人授课、无视频讲课 |
| 周末/节假日禁止 | 周末、节假日、寒暑假均可使用 |

### 9.2 宣传话术合规红线

**禁止词汇**：培训、补课、辅导、提分、培优、补差、应试冲刺

**合规用词**：大屏护眼学习工具、AI 个性化练习、学习习惯养成、能力专项训练

**标准合规文案**：
> 专为上海 6-10 岁儿童设计的大屏护眼 AI 学习工具，通过游戏化交互辅助语数英阅读、口算练习与思维能力培养，主打自主学习习惯养成，不授课、不补课、不超前教学。

### 9.3 网站与 App 备案合规

| 备案类型 | 要求 | 说明 |
|----------|------|------|
| ICP 备案 | 必须 | 国内服务器域名必须备案，个人/个体户均可 |
| 公安联网备案 | 必须 | 网站上线后必须完成 |
| 教育移动应用备案 | 必须 | 按教育类 App 要求完成教育部备案 |

### 9.4 儿童隐私数据合规

| 要求 | 具体做法 |
|------|----------|
| 数据最小化 | 仅收集家长手机号、孩子年级/年龄段 |
| 用户授权 | 注册页增加家长知情同意弹窗 |
| 数据安全 | 加密存储，不泄露、不贩卖 |

### 9.5 经营主体分阶段规划

| 阶段 | 年收入 | 经营主体 | 必办事项 |

| 阶段1 | <10万 | 个人即可 | ICP备案、公安备案、隐私合规 |

### 9.6 合规永久底线

1. 永远不做真人授课、不做学科培训类业务
2. 永远不使用违规宣传话术
3. 儿童隐私、网站备案、内容版权从项目第一天就规范设计

## 十、改进建议汇总

> 以下是从对话中识别出的关键改进点，应在下一版本中纳入：

### 10.1 产品设计改进

1. **绘本图片方案**：采用「固定卡通插画库+AI排版」方案，而非纯AI生成，确保画风统一稳定
2. **手柄操控**：接入无线 2.4G USB 手柄，完全息屏投屏，学习游戏化
3. **双人/亲子模式**：考虑加入亲子互动模式，家长和孩子一起学习

### 10.2 技术改进

1. **异步任务队列**：AI 生成绘本/题目时使用异步队列，避免阻塞前端
2. **离线缓存**：支持本地缓存已生成的绘本，供离线使用
3. **学习数据可视化**：为家长提供清晰的学习进度报告

### 10.3 运营改进

1. **先做最小可行产品**：先集中做好一个科目（建议数学），快速验证
2. **内容先行**：先积累100+绘本、500+题目再对外开放
3. **社区运营**：建立家长社群，及时收集反馈快速迭代

### 10.4 商业模式改进

1. **试用转化**：7天免费试用 → 限时优惠价转化
2. **口碑裂变**：老用户推荐新用户享折扣
3. **年度套餐**：推多年套餐提升续费率
